# AB-new — تطبيق الجوال 📱

بوت تداول pump.fun بواجهة رسومية عربية — **وضع ورقي (افتراضي)** + وضع حقيقي (قريباً).

## المزايا
- 🖥️ واجهة عربية كاملة: رئيسية / مراكز / سجل / إعدادات
- 📝 **وضع ورقي**: يتداول بأموال افتراضية على أسعار حقيقية مباشرة
- 🔔 إشعارات لكل صفقة
- 🌙 يعمل بالخلفية (WakeLock) — لا يتوقف عند إغلاق الشاشة
- 📊 إحصائيات مباشرة: رصيد، ربح/خسارة، نسبة نجاح
- ⚙️ إعدادات مرنة: حجم الشراء، جني الأرباح، وقف الخسارة، محافظ النسخ

## البناء
يُبنى الـ APK تلقائياً عبر GitHub Actions عند كل دفع — الناتج في `releases/AB-new-latest.apk`.

## التشغيل للتجربة (ويب)
```bash
cd app/ab-new && npm install && npm run dev
```
